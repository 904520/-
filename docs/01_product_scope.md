# 01 产品范围与需求定义

## 1. 产品目标
在用户上传证据材料后，辅助生成结构化、可提交的维权文书，提高普通用户维权效率。

## 2. 目标用户
- 劳动纠纷用户
- 消费维权用户
- 行政争议用户
- 中小企业法务/人事

## 3. 核心能力清单
1) 材料收集
- 上传 PDF、图片、音频、视频、文本
- OCR 与语音转写
- 自动分类（合同、聊天记录、票据、通知）

2) 智能分析
- 事实提取（时间、地点、人物、行为）
- 证据链完整度评估
- 争议焦点识别
- 时效与管辖提示

3) 文书生成
- 投诉举报材料
- 行政复议申请书
- 信访材料
- 民事起诉状/答辩状（后续扩展）
- 文书模板个性化（地区、事项类型）

4) 用户体系
- 手机号/邮箱注册登录
- 会员订阅（按月/按年）
- 免费额度与会员权益

5) “思考能力”展示
- 展示“分析摘要”和“依据来源”
- 给出不确定项与补充材料建议
- 禁止伪造事实、禁止保证胜诉

## 4. 非功能要求
- 移动端优先（iOS/Android）
- 高可用：核心服务可用性 99.9%
- 数据安全：敏感信息加密存储与传输
- 可追踪：关键 AI 输出可审计
