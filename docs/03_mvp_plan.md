# 03 MVP 落地计划（12 周）

## 阶段 1（第 1-2 周）：需求冻结与原型
- 完成用户故事与流程图
- 完成移动端关键页面原型
- 明确文书模板首发范围（4 类）

## 阶段 2（第 3-5 周）：后端基础能力
- 注册登录 + 会员体系
- 文件上传与存储
- OCR/ASR 接口打通

## 阶段 3（第 6-8 周）：AI 文书能力
- 建立证据结构化流水线
- 实现首版“投诉举报材料”自动生成
- 支持人工改写与版本对比

## 阶段 4（第 9-10 周）：多文书扩展
- 上线复议申请书、信访材料模板
- 增加证据缺口提示和风险评分

## 阶段 5（第 11-12 周）：灰度上线
- 小流量内测
- 修复高优先级缺陷
- 发布移动端安装包（TestFlight/Android 内测）

## MVP 验收指标
- 文书首稿生成时间 < 60 秒
- 80% 用户可在 20 分钟内完成首次文书导出
- 关键流程崩溃率 < 1%
