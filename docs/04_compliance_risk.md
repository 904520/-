# 04 合规与风控要点（必须落地）

## 1. 法律与业务边界
- 产品定位为“法律信息与文书辅助工具”，非律师执业替代
- 明示免责声明：系统输出不构成法律意见
- 对“保证胜诉”“伪造证据”等请求强制拦截

## 2. 数据合规
- 用户协议与隐私政策独立展示并强制同意
- 敏感字段加密（身份证号、联系方式、地址）
- 最小化采集：仅收集服务所需信息
- 提供“删除账户与数据”能力

## 3. AI 风险控制
- 输出前做事实一致性检测
- 标注引用证据来源（文件名 + 段落）
- 高风险场景触发人工复核建议

## 4. 安全措施
- 全链路 HTTPS
- 对象存储私有化 + 临时签名访问
- 防刷、防撞库、防越权
- 审计日志防篡改

## 5. 上线前清单
- 完成渗透测试与依赖漏洞扫描
- 完成隐私影响评估（PIA）
- 完成客服与纠错机制（用户可反馈文书错误）
